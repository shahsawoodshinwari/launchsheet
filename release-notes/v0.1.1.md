# 🚀 Release v0.1.1

**Project:** Launchsheet  
**Release Date:** 2026-11-25  
**Release Type:** Patch  

---

## 📋 Release Overview

This release makes Launchsheet safer and easier to read. The extension is now limited to App Store Connect tabs, the activity log explains each step in plain language, and the CSV preview shows every value a run will use before anything is saved.

## ✨ New Features

- **Full CSV preview**: each app is an expandable block showing SKU, version, primary language, copyright, categories, review contact, demo account (password masked) and review notes. Each locale expands to show all nine listing fields with character counts, and fields left empty are marked "left unchanged".
- **Inline confirmation**: turning Dry run off and pressing Run now shows a "Save changes to N apps?" bar in the panel, replacing the browser dialog.

## 🔧 Improvements & Enhancements

- **Tab scope**: the toolbar icon and side panel are enabled only on `appstoreconnect.apple.com` tabs and are greyed out everywhere else. A run acts only on the tab the panel was opened from, rather than any App Store Connect tab it could find.
- **Activity log**: steps use plain labels, for example `Store listing (en-US): up to date`. Name changes show as old to new, each app ends with a "changed / already up to date" count, and the run ends with a one-sentence summary. API paths and codes moved to the page console.
- **Categories**: skipped when the app already has the requested categories, so repeat runs report "up to date" instead of rewriting them.

## 🐛 Bug Fixes

- **Stale script after reload**: re-opening the panel after reloading the extension could leave an older copy of the page script handling runs. The newest copy now replaces it.
- **Unnecessary category writes**: every run re-saved categories even when nothing changed (see Improvements).

## 🏗️ Technical Changes

- Backend/API changes: none. The same App Store Connect web API calls are used.
- Frontend/UI changes: new `panel/preview.js` (pure `previewModel()` plus DOM rendering), inline confirmation bar, restyled panel.
- Infrastructure, configuration, or dependency changes: `background.js` now enables the action and side panel per tab. Permissions are unchanged (`sidePanel`, `scripting`, and host access to `appstoreconnect.apple.com` only). No new dependencies.
- Refactoring and code quality: content script restructured around reusable step helpers. Test suite grew from 7 to 10 tests. `npm version` now keeps `manifest.json` in sync, and the release workflow publishes notes from `release-notes/`.

## ⚠️ Breaking Changes

*No breaking changes in this release.*

The CSV format is unchanged. Note that the toolbar icon is now greyed out on non-App Store Connect tabs, so open App Store Connect first.

## 📌 Known Issues & Follow-ups

- **Limited verification**: the App Store Connect calls have been exercised on a single account. Categories and App Review information are newer and less proven than the listing text steps, so run a dry run first.
- **Undocumented API**: the extension relies on App Store Connect's private web API, which Apple can change without notice.
- **Follow-up**: Google Play support, `.xlsx` upload, screenshots, age rating and pricing are planned for future releases.
